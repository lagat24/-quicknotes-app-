# QuickNotes

QuickNotes is a simple note-taking web app that lets users create, organise, search and delete notes.
Notes are divided into Personal, Work and Study categories.
They are automatically saved in the browser so they remain available after refreshing the page.

## Features

1.Add notes
2.Add categories - Personal, Work and Study.
3.Delete notes
4.Search notes
5.Note count updates automatically
6.Notes persists.
7.Category-specific visual styles

## How to Run Locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your notes.

No server or additional dependencies are required.
